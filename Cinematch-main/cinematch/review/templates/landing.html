How CineMatch Works

A three-stage machine learning and natural language pipeline

1. Vector Space Engine

Merges metadata (cast, director, genres, keywords, plot) and uses Snowball stemming with TF-IDF to create 5,000-dimensional semantic vectors.

2. LSTM Sentiment Model

Trained on 50,000 IMDB movie reviews to classify community critiques as Positive or Negative with 87.43% test accuracy.

3. Resilient SVG Proxy

In-memory cached server-side proxy that overcomes third-party CDN blocks and dynamically generates stylized cinema SVG posters when needed.
